# 2026-11-09 项目版本更新

本次在仓库 `main` 的初始 MVP 提交 `8773383` 基础上更新完整项目，覆盖账号与多项目协作、团队 Git 工作区、主页行动推荐、个人中心与贡献成长体系。服务器应用已于 2026-11-09 部署，详情见 [上线记录](DEPLOYMENT-20261109.md)。本次 GitHub 更新保留原有提交历史。

## 功能变化

### 账号、多项目与模型配置

- 新增注册、登录、会话管理、创建项目、邀请码加入和项目成员访问控制。
- 支持团队与个人 Agent 协作、任务分配与交付审查；项目模型配置加密保存，个人模型按项目独立管理。
- 新增团队共享研究资料及证据，支持检索、归档和恢复。
- 当前数据库切换为 MySQL，保留原 SQLite 迁移历史于 `prisma/sqlite-migrations`；新迁移不会自动导入旧 SQLite 数据。

### 团队协作与 Git

- 支持每个项目配置自己的仓库，导入已有内容及私有 GitHub 仓库。
- 提供文件与目录浏览、多文件/文件夹上传、文本编辑、新建、重命名和删除。
- 支持个人工作分支、提交说明、提交历史、差异查看、创建者审查合并、快进拉取和确认推送。
- 保留团队任务交付 → 任务分支 → 审查合并 → 推送的流程，项目邀请码统一使用项目页入口。
- Git 冲突在线编辑、完整远程分支管理、GitHub PR 集成、代码运行及 CI/CD 仍未实现。

### 我的下一步

- 仅在个人主页展示跨项目的待处理和等待事项，支持项目筛选、刷新和具体事项跳转。
- 项目优先级由个人设置为 1–5 星；同星级结合紧急程度、阻塞情况、截止日期等推荐。
- 只从任务描述识别明确截止时间；未指定时才允许设置个人截止时间，相对日期固定按任务创建时间解释。

### 个人中心

- 支持昵称、简介、专业方向和技能标签；头像支持预设图案和本地 JPG/PNG/WebP 图片。
- 增加清晰可点击的个人中心入口；本地头像校验后压缩、裁剪并保存。
- 管理个人 Agent 回答风格、技术偏好、交付格式和工作习惯；保存后的偏好会传入新的个人模型请求。
- 支持验证原密码后改密、登录设备查看和撤销其他会话。
- 收藏文档、证据和 Agent 回复，并支持搜索、标签、笔记及原位置跳转；失去项目权限后隐藏原内容。

### 贡献与成长

- 新增按账号累计的经验账本、贡献统计、项目筛选和贡献时间线。
- 创建者确认任务交付 +30、独立成果采纳 +10；审核他人有效贡献 +10；符合条件的里程碑参与者 +20。
- 同一来源幂等计分，撤销认定联动回退审查和里程碑经验；历史贡献需要明确认可后才计入。
- 提供七级成长体系，门槛为 0、100、300、700、1500、3000、9999；最高为 Lv.7「项目狂人」。
- 卡片配色、徽章、边框与纹饰随等级递进，支持等级图鉴预览；减少动态效果设置可关闭扫光。

### 稳定性与数据

- 完善研究文档输出截断识别与有限重试，保留已生成文件和任务上下文。
- 新增个人优先级、个人资料、收藏、头像与贡献记录相关增量迁移；会话标识使用数据库默认值兼容旧客户端。
- 保留现有账号、项目数据及加密模型配置，不重置业务数据。
- 不再跟踪 Next.js 自动生成的 `next-env.d.ts`，避免提交本机临时构建路径；`npm run typecheck` 会先生成路由类型再检查。

## 升级说明

提交源码、package-lock.json、Python uv.lock、Prisma schema 与迁移目录；不提交真实环境文件、SSH 私钥、数据库备份、Git 私有凭据、依赖或构建缓存。

已有部署应保留原生产环境配置和 SCENARIOFORGE_SETTINGS_KEY，先备份，再在独立目录按锁文件安装依赖、生成 Prisma 客户端和构建；按部署说明完成任务状态检查、迁移及版本切换。生产只使用 migrate deploy，不执行 migrate dev、db push 或数据库重置。GitHub 提交不会自动再次部署服务器，除非另行配置了部署工作流。
