# 示例输入

## 软件项目

我想做一个帮助东京留学生找合租室友的应用。预算低，团队 3 人，两周内完成课程演示。

约束：截止时间“两周”；团队人数 3；预算“低”；技术偏好“Next.js”。可以上传自己的课程要求或产品需求文档。

检查：先研究现有平台、目标用户与实施约束，再提出 MVP 范围；市场判断应有来源；预算、房源真实性与隐私风险应区分事实、建议和待确认事项。

## 研究项目

我想调研安全帽检测的常用数据集、模型和评估指标，为后续做一个计算机视觉课程项目做准备。

检查：数据集、论文与模型名称有实际来源；无法核实的授权、规模和性能标记“待确认”；方案比较不编造实验结果。

## 活动策划

我想为东京的中国留学生组织一次中秋交流活动，预算有限，预计 30 人参加，需要活动流程和分工。

检查：地点、日期和预算存在关键缺口时发起澄清；地点费用和预约条件有来源或标为待确认；执行计划包含分工、时间和风险应对。
