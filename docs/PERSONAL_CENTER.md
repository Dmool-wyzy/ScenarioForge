# 个人中心

入口：主页和项目页右上角的账号区域，或访问 `/profile`。个人中心独立于项目工作区，沿用原有绿色卡片风格；手机端导航排列在内容上方。

## 第一版功能

- 个人资料：昵称、六款可选头像或本地上传头像、简介、专业方向、技能标签。支持 JPG/PNG/WebP，原图最大 5 MB，自动居中裁为 256 × 256 正方形；预览后点击「保存资料」生效。服务端重新解码并统一为 WebP，数据库保存处理后的头像，主页右上角同步展示。
- 个人 Agent：跨项目共享回答风格、技术偏好、交付形式和补充习惯。偏好会进入下一次子任务初稿或个人追问的模型请求，明确任务及当前补充要求优先。偏好不会扩大工具权限，也不会自动共享个人对话。
- 按项目管理已有个人模型、测试连接、接收授权和清除配置。个人 API Key 的加密存储方式不变；更换 API 地址仍需重填 Key。项目内保留任务收件箱，配置入口跳转到个人中心。
- 账号安全：验证当前密码后更新密码、查看有效登录会话、退出单个其他会话或全部其他会话。密码更新撤销所有旧会话并给当前设备创建新会话。设备名称根据登录时的浏览器标识概括；更新前的登录显示“历史登录设备”。
- 收藏：工作区文档、证据卡、团队 Agent 回复、研究结论、自己的个人 Agent 回复。支持搜索、类型筛选、最多八个标签、个人笔记和取消收藏。点击标题回到原项目及内容位置。

收藏保存引用，读取时重新核对当前项目成员权限；原内容删除或退出项目后显示“原内容已不可访问”，不返回原文和链接。个人回复仅任务接收者可收藏。原内容变动后收藏预览随之更新，每项预览最多 1500 字；收藏不参与 Agent 上下文自动注入。

- `20261109020000_personal_center` 新增 `UserProfile`、`PersonalFavorite`，给 `AuthSession` 增加独立标识和设备描述。
- `20261109020100_session_id_default` 为会话标识增加数据库默认值，兼容尚未更新的已部署客户端。
- `20261109030000_custom_avatar` 扩大头像字段容量以保存处理后的图片，原默认头像保留。
- 现有账号、项目、模型配置和个人截止日期保留；无数据重置。
- 本地使用现有 `projectdb`。代码发布到公网服务器需要单独部署，不能仅凭数据库迁移认为公网界面已更新。
